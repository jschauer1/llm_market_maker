All three second-wave workers loaded their full skill twice, while some never
reached the relevant evidence before supervisory intervention. See
docs/agents/behavior-trial-2026-09-04.md for measurements and repeatable cases.
The 8,000-word target was an experimental supervisor choice; the user clarified
that useful additional reading is welcome.

Make skill entrypoints small and route substantial procedure details into phase
references without duplicating or weakening authoritative rules. Preserve easy
access to deeper context and agent discretion to read it. Any retrieval metrics
should help identify repetition, not impose a default cap. Validate completed
decisions against the relevant evidence and reduce redundant instruction
loads; total words alone are not a success criterion. Keep the work focused on
context organization.
