# Agent context trial: decision quality and redundant reading

Two waves of three fresh agents exercised the shared skills in private Markdown
copies. Floor reporting and memory recording used `gpt-5.6-luna` at medium effort;
research triage used `gpt-5.6-sol` at medium effort. The objective was useful,
executable edge decisions with less research spend. No live trading, ledger
writes, collection, or market research occurred.

## Observations that change the workflow

| Case | First wave | After instruction changes |
|---|---|---|
| Completed floor receipts | Correct supported subset and exclusions, but converted 2,000 offered contracts into suggested stake and invented queue/recording status. | Correct candidate, explicit simulation label, size unset, unsupported ledger fields marked missing. |
| Existing-theory research | Rejected broad-null and live-only arguments, but recommended calendar waiting without establishing historical-data availability. | Chose a saved-evidence audit before further spending; did not reach the actual study results within the supervised allowance. |
| Completed study recording | Saved a synthetic lesson with conditions weaker in its summary/action than in its applicability field. | Preserved the source and avoided a new card, but called it redundant from a map without comparing the existing card. This does not pass consolidation review. |

All six workers avoided whole-archive reads. Memory format checks passed in the
first wave despite the semantic errors: schema compliance is insufficient.

## Reading cost

| Case | First wave | Second wave |
|---|---:|---:|
| Floor | 23,082 | 19,626 |
| Research | 33,927 | 13,413 |
| Recording | 12,668 | 11,094 |

These are words emitted by the instrumented reader, including line labels,
rereads and generated artifacts. Truncated output may not all reach the model;
these are **not billed tokens**. Every run exceeded the approximate 8,000-word
target assigned by the supervisor for this experiment. The user did not request
that target and subsequently clarified that agents should read more whenever
they judge it useful. Exceeding it is not itself a negative result. Supervisory
stop messages bounded further work, and some queued reads finished around
delivery. Those interventions also prevented some evidence review, limiting
what this trial establishes about task completion.

Full skills were repeatedly loaded, including a double load in each second-wave
case. Some irrelevant README/manifest reads remained. Lower second-wave counts
also reflect incomplete work, so they do not establish an efficiency gain.

## Changes and next decision

The canonical floor skill now separates depth from stake and requires verified
queue facts. Policy routing and lane skills distinguish bounded assignments
from full execution. Theory stopping rules check captured data and eligible
tier A/B replay before calendar waiting. Memory rules put scope in summaries
and actions, and require comparing a card before declaring duplication. That
last clarification was added after wave two and has not had a fresh-agent test.

The next improvement should reduce duplicate instruction loads and make
procedure references easier to select by phase. Preserve full authoritative
procedures and let agents retrieve further context whenever useful. Reading
metrics can diagnose repetition; they should not enforce an arbitrary default
cap or reward an incomplete task. Evaluate whether agents reach the relevant
evidence and make sound decisions, including when deeper reading is necessary.

## Repeatable cases and review bar

- Floor: a ready subset with eligible tier B evidence and no live outcomes;
  a post-hoc one-event pilot; a basket whose asks exceed payout. Only the subset
  merits attention. Offered depth supplies no stake size or ledger status.
- Research: a broad null, narrowly registered cells, and proposals to recollect
  expired data or mine fresh bands. Inspect applicable saved evidence before
  waiting, spending, or declaring no edge; retain full eligible A/B weight.
- Recording: a synthetic offset-resume failure under changing sort order,
  plus diary noise and an untested liquidity claim. Compare the existing card;
  retain only a scoped mechanism/action that adds value, or explain uncertainty.

Local cases, private edits, hashes and read traces remain under ignored
`.superpowers/sdd/memory-trial/`. One observation per model/case/wave cannot rank
models, validate Claude runtime behavior, or demonstrate profitability.
