# Find historical rationale

Use these sources to resolve a specific historical question. Current rules
come from AGENTS, the mapped guide sections, and canonical skills. Old diary
instructions and old Next lists do not assign work today.

- [Original research log through 2026-09-04](research-log-through-2026-09-04.md) — Retrieve the dated rationale behind a ruling, migration, or earlier result when its current owner needs clarification.
- [Theory-specific history](../theories.md) — Find the owner and its evidence links before searching an entire cross-project diary.

The original log is preserved verbatim. Its plain-text paths were relative to
the repository root. Search its headings for the date or topic first, then
read the matching entry; do not load the full file to orient. New rotated log
segments earn a summary link here only when it helps retrieve a consequential
decision. Split this map by question or period before exceeding 12 entries.
