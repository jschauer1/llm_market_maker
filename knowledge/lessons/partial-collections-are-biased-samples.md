# Treat an interrupted ordered collection as its own sampling frame

**Summary:** Freeze and label an interrupted collector's exact state, including traversal order, before interpreting any result from it.
**Applies to:** Kalshi series walks ordered alphabetically or by settlement count during the 2026-08-29 through 2026-09-03 series-bias campaign.
**Finding:** Observed — a 227-of-659 alphabetical prefix suggested a below-0.80 favorite effect; the completed series-bias sweep removed that effect. Cheapest-first collection also selected lower-frequency series. These directions are collection-specific, not universal sampling corrections.
**Do next time:** Record ordering, progress, stop time, eligible remainder, and collection state; call a partial result a prefix or size-truncated population and never the board.
**Evidence:** [Series-bias study](../../tickets/study/investigation/2026-08-29-series-bias-mining/STUDY.md), headings “Appended 2026-09-03” and “Pass 4 result — run 2026-09-03, on the COMPLETED sweep”
**Revisit when:** Collection order is randomized or the target population is fully captured.
