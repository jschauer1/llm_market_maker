# <Theory> — source notes

Start at [the learning map](learnings/README.md) for reusable findings.
Additional narrative uses `notes/YYYY-MM-DD-<question>.md`, at most 1,200
words, with the outcome and scope first, followed by the question, test,
limitations, and exact inputs/results/run IDs. If a campaign or study already
holds it, link it rather than writing it twice. Preserve paid judgments and
captures in their existing stores.

A useful conclusion earns a scoped card and a map entry; open work goes in
an owner ticket. No useful learning means no card. Follow
`docs/agents/research-memory.md` from the repository root.
