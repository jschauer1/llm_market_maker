# Procedural Bottlenecks — learning map

- [Keep the FDA conclusion scoped](fda-obstacles-survive-legislation-failure.md) — The narrow FDA barrier screen duplicated disclosures at expensive NO prices; this does not settle other classifications or the board-wide hypothesis.
- [Audit what judges actually researched](audit-research-and-exact-predicates.md) — Schema-valid outputs can conceal unresearched defaults; verify source interpretation, rule exclusions and issuance timing before accepting an actionable classification.
- [Compress after locating program status](compact-packets-need-current-status.md) — Valid hashes and short packets can still omit decisive timelines or scanned deficiencies; check completeness before compression and exclude collector conclusions from blind input.
- [Check opportunity economics before building](../../../knowledge/lessons/check-opportunity-economics-before-building.md) — Thirty active policy-condition markets did not establish recurring, rule-matched supply for a named-bill prototype; measure potential capacity before further heavy work.
- [Legal possibility does not establish a supported path](legal-possibility-is-not-supported-route.md) — Five blind development labels collapsed to plausible_path; review found missing evidence treated as route support. Clarify this boundary before scaling replay spend.
- [Fixed-time historical replay is not yet feasible](fixed-time-history-is-incomplete.md) — Ten frozen KXBILLS cases had zero exact 12:00 plus 12:15 quote pairs, and nine current source files were historically late.
